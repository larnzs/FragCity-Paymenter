# FragCity Design System

## Brand palette

| Token | Color |
|---|---|
| Background | #0D0D0D |
| Surface | #171717 |
| Primary | #F97316 |
| Accent | #FFB347 |

## Design goals

- Consistent visual language across customer pages.
- Responsive layouts for desktop and mobile.
- Clear service status and resource information.
- Reusable cards, forms, tables, navigation and modal components.
- Accessible contrast and interaction states.

## Scope

The customer-facing theme lives in `themes/fragcity`.

The Filament administration interface is a separate design surface
and will be customized through the extension and supported Filament
integration points.
